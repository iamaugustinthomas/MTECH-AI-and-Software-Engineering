\section{Set Builder Form}
\begin{frame}{Set Builder Form}

\begin{enumerate}
    \item A=\{ $1,\dfrac{1}{2},\dfrac{1}{3},\dfrac{1}{4},... $\} \\
    \vspace{1ex}
    Set Builder Form: \\
    \vspace{1ex}
    
    \pause
     \hspace{6em} A=\{$\dfrac{1}{n} \mid n \in \mathbb{Z}^+ $ \}
     \vspace{2ex}
     \pause
    \item Using Cartesian plane, write set $ Q_1$ of all coordinate points (x,y) in first quadrant \\
    \vspace{1ex}
      Set Builder Form: \\
    \vspace{1ex}
    \pause
     \hspace{3em} $ Q_1=\{(x,y)\mid x,y \in \mathbb{R} \ and \ x>0 \ and \ y>0 $ \}
\end{enumerate}
\end{frame}

\pause
\textbf{1.Machine Learning Datasets} \\
\vspace{1ex}
\pause
A machine learning dataset is a structured collection of data used to train, validate, and test artificial intelligence models.\\
\vspace{2ex}
\pause
\begin{itemize}


\item \textbf{Total Dataset}
A total dataset $\mathbf{D}$ is partitioned into input and output pairs (x,y) \\
$D= \{(x_i,y_i)\mid i\in\ \mathbf{N}$
\vspace{2ex}
\pause
\item \textbf{Training Set}\\
$ \mathbf{D}_{Train}=\{(x_i,y_i)\in D \mid i \in \mathbf{I}_{Train} \}$  where $ \mathbf{I}_{Train}$ contains the specific training indices.\\
\vspace{2ex}
\pause
\item \textbf{Test Set}\\
$ \mathbf{D}_{Test}=\{(x_i,y_i)\in D \mid i \in\mathbf{N}\ and\ i \notin \mathbf{I}_{Train} \}$  where $ \mathbf{I}_{Train}$ contains the specific training indices.\\
\end{itemize}
\end{frame}
