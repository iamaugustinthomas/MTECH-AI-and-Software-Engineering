\section{General form of Inclusion-Exclusion Principle}
\begin{frame}{General form of Inclusion-Exclusion Principle}

For finite sets $A_1, A_2, A_3, \dots, A_n$, the total number of elements in their union is:
\vspace{0.5em}

\[ 
\begin{aligned}
\left\lvert \bigcup_{i=1}^{n} A_i \right\rvert &= \sum_{i=1}^{n} |A_i| \\
&\quad - \sum_{1 \le i < j \le n} |A_i \cap A_j| \\
&\quad + \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k| \\
&\quad - \cdots \\
&\quad + (-1)^{n-1} |A_1 \cap A_2 \cap \cdots \cap A_n|
\end{aligned}
\] 

\end{frame}

\section{General form of Inclusion-Exclusion Principle}
\begin{frame}{General form of Inclusion-Exclusion Principle}

For finite sets $A_1, A_2, A_3, \dots, A_n$, the total number of elements in their union is:
\vspace{1em}

\[ 
\left\lvert \bigcup_{i=1}^{n} A_i \right\rvert = \sum_{k=1}^{n} (-1)^{k-1} \left( \sum_{1 \le i_1 < i_2 < \dots < i_k \le n} |A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}| \right)
\] 

\end{frame}

\section{Poset}
\begin{frame}{What is a Poset?}
A partially ordered set is a a set where we have defined a specific rule fro how elements in a set relate to each other.\\
\vspace{1 ex}
For a set to be a poset, the following three conditions must be met 
\begin{itemize}
    \item Reflexive: Every item relates to itself.
    \item Antisymmetric: If item $\mathbf{A}$ relates to item $\mathbf{B}$ and item $\mathbf{B}$ relates back to item $\mathbf{A}$, then they must actaually be the exact same item.
    \item Transitive If $\mathbf{A}$ relates to $\mathbf{B}$ and $\mathbf{B}$  relates to $\mathbf{C}$ , then $\mathbf{A}$ automatically relates to $\mathbf{C}$ 
\end{itemize}

    
\end{frame}
